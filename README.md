# git-shell-admin-uebung

Kleines Administrationsprojekt mit eigenen Shell-Skripten, entwickelt mit Git Branches.

## Skripte
- systeminfo.sh – zeigt Systeminformationen an
- dateipruefung.sh – prüft, ob eine Datei existiert
- projektstruktur.sh – erstellt automatisch eine Projektstruktur
- admin-menu.sh – Terminal-Menü mit allen Funktionen

## Nutzung
Jedes Skript kann mit folgendem Befehl gestartet werden:
bash scripts/DATEINAME.sh
